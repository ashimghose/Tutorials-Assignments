# Site fonts

Self-hosted so the static site makes no requests to Google and the files are cached with the build.

- Source Serif 4 (headings), weights 600–700, Latin and Latin Extended subsets.
- Source Sans 3 (text), weights 400–700, Latin and Latin Extended subsets.

Both are by Adobe under the SIL Open Font License 1.1 (https://openfontlicense.org), downloaded from
Google Fonts. The `@font-face` rules are in `resources/css/site.css`.
